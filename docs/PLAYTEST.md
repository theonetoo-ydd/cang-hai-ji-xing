# 《沧海纪行》v0.5 试玩启动指南

## 环境

- Godot 4.3 或更高的 Godot 4.x；
- 当前试玩版不需要额外插件；
- 分辨率基准：1280 × 720。

## 最简单的启动方式

1. 下载或克隆仓库；
2. 打开 Godot Project Manager；
3. 选择 **Import**，定位仓库根目录的 `project.godot`；
4. 打开项目；
5. 点击右上角 **Run Project**（F6/F5 均以项目主场景为准时，推荐直接 F6? No—使用 F5 / Run Project）；
6. 游戏会从宁波港开始，初始资金 1000 两。

推荐使用 **F5 / Run Project** 启动整个项目。

## 命令行启动

在仓库根目录执行：

```bash
godot --path .
```

如果系统中的命令名是 `godot4`：

```bash
godot4 --path .
```

## 第一次怎么玩

启动后会显示“初航指引”：

1. 宁波商馆选择【绫】丝绸；
2. 建议买入 5 份；
3. 点击左侧“出航 / 海图”；
4. 在海图选择广州；
5. 点击“扬帆出航”；
6. 抵达广州后卖出丝绸；
7. 资金高于初始 1000 两即完成第一笔跨港盈利。

之后可尝试连续路线：

```text
宁波：买丝绸
  ↓
广州：卖丝绸 / 买砂糖
  ↓
泉州：卖砂糖 / 买胡椒
  ↓
宁波：卖胡椒
```

按当前测试价格，不计随机航海货损时：

- 初始资金：1000；
- 回到宁波：1205；
- 游戏日：第 14 天；
- 理论净增：205。

## 自动测试

```bash
godot --headless --path . --script res://tests/test_runner.gd
```

当前测试包括：

- 买入；
- 货舱容量限制；
- 卖出利润；
- 航行状态转换；
- 存档读回；
- 宁波 → 广州 → 泉州 → 宁波连续三港贸易。

测试通过时退出码为 0。

## 存档

顶部使用“保存 / 读取”。

正常存档：

```text
user://savegame.json
```

测试存档使用独立文件，不会覆盖正常存档。

# ADR-001：首版技术栈

- 状态：Accepted
- 日期：2026-09-30

## 决策

《沧海纪行》首版 MVP 使用：

- **Godot 4.x**
- **GDScript**
- 2D UI 优先
- 数据与规则逻辑尽量保持与表现层分离

## 原因

1. 安装简单，适合个人与小团队快速原型。
2. GDScript 语法接近 Python，新手学习成本较低。
3. 2D UI、场景树、信号系统足以支撑首版港口交易与航行流程。
4. 项目文件大多为文本，便于 Git 管理和代码审查。
5. 当前 MVP 重点是贸易闭环，不需要大型 3D 引擎能力。

## 当前最低运行要求

建议使用当前稳定的 Godot 4.x 版本打开仓库根目录。

仓库中的 `project.godot` 会将：

```text
res://scenes/Main.tscn
```

作为启动场景。

## 运行

GUI：

1. 安装 Godot 4.x。
2. 打开 Godot Project Manager。
3. Import 项目并选择仓库根目录的 `project.godot`。
4. 点击 Run Project 或按 F6/F5。

命令行：

```bash
godot --path .
```

部分系统的可执行文件名可能是：

```bash
godot4 --path .
```

## 当前验证目标

成功启动后应看到：

- 标题：`沧海纪行`
- 副标题：`明代航海 · 贸易 · 探索`
- “开始航行”按钮
- MVP 状态提示

点击“开始航行”后，状态文字会提示下一步开发 T03–T07 贸易核心。

## 后续

只有当 Godot 4.x 无法满足明确需求时才重新评估技术栈，避免在 MVP 阶段频繁切换引擎。

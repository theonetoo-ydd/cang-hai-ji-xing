# v0.5 已知问题与范围限制

更新目标：第一次可试玩版本。

## 需要实机确认

1. **尚未在当前开发执行环境实际启动 Godot。** 代码、资源路径和流程已做静态检查，但 v0.5 仍需要在 Godot 4.3+ 中完成一次启动验收。
2. **headless 自动测试尚未在当前环境实际执行。** 当前环境没有 Godot 可执行文件。
3. 1280 × 720 是当前 UI 基准分辨率，其他窗口尺寸仍需视觉验收。

## 已知功能限制

- 当前只有宁波、泉州、广州 3 个港口；
- 当前 6 种商品价格是固定的玩法测试数据，不是动态市场，也不代表历史真实价格；
- “价低 / 价高 / 活跃 / 平稳”目前是快速提示规则，不是供需模型；
- 航海事件为随机事件，自动测试暂不覆盖随机结果本身；
- 风浪货损提示目前只显示损失数量，尚未在主 UI 中显示损失商品名称；
- 当前为手动单档保存/读取，尚未加入自动保存；
- 新手提示关闭状态不会写入存档，重新启动游戏会再次显示；
- 船厂和酒馆按钮为后续系统入口，v0.5 中保持禁用；
- 港口场景、船只与商品目前主要使用 UI 占位和符号化表现，正式插画/图标/音效尚未接入；
- 尚未加入补给、船员、船只升级、任务、战斗、声望、动态经济等扩展系统。

## v0.5 不视为问题的内容

v0.5 的验收重点是：

```text
启动 → 看懂引导 → 买货 → 出航 → 抵港 → 卖货 → 盈利 → 继续跑商 → 保存/读取
```

只要这条闭环稳定，扩展系统留到 v0.6 以后。
